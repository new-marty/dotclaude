# 認知リズムを生むための日本語ライティング規範

密度の高い文章が退屈になるのは、情報が多いからではなく、全文が同じ認知モードで書かれているからである。
読者の認知モード（観察する、迷う、確信する、確かめ直す）を切り替え、常に「続きを読む理由」を維持する。

作業前に `z-japanese-proofreading` を読む。

対象は読み物として読ませる章や記事に限る。手順書、参照用の文書、決定記録、業務の説明文書には使わず、
`z-writing-for-readers` に従う。文書の冒頭で、読者に前提として求める知識と扱わないことを書く 1〜2 文は、
下の「予告」や「文書を更新する文」には当たらない。

## 中心にある判定

**その文が更新するのは「状況」か、「文書」か。** 全体がこの一つの軸で動く。

- **状況を更新する文** — 対象世界の出来事・データ・発言、または語り手の判断の状態（思い込み、保留、後悔、譲歩、告白）を新しく伝える。残してよい。
- **文書を更新する文** — この章・この節・ここまでの話が「どう見えるか」「次に何を書くか」だけを伝える。削除する。

新しく書くときも同じ。拍・緊張・緩みの材料は状況側からしか取らない。状況に材料が見つからない位置には、
何も足さず平坦なまま残す。拍を作るために文を削るのではない。導入で必要な文脈共有（範囲、観点、比較軸、
未確定事項）を削って短くするのは、緩急ではなく欠落である。

## 駄文の典型

いずれも話題が本文自身で、状況の情報がゼロ。

- 「ここまでだと、概念の説明に見えるだろう。なので、すぐに例へ戻す。」
- 「要するに、この章の主題は〜ではなく〜である。」
- 「誤解しないでほしいのだが、〜を否定したいわけではない。」（退ける誤読を特定していない）
- 「テクニックの列挙はしない。」「問いは〜だけである。」（本文の性格・範囲の宣言）
- 「先に答えを半分だけ置く。」「最後にもう一度だけ線を引く。」（これからやる操作の宣言）
- 「ここまでで〜は見えた。次は〜を見る。」（節末の進行予告）

短くリズムの良い断定形は、駄文の最大の混入経路である。文書更新の文を削らずに短く整形すると、
決め台詞に見えて残る。短さは残す理由にならない。

## 文書について述べてよい4つの形

1. **反論処理** — 退ける誤読を「」で具体的に引用して退ける。漠然と「誤解しないでほしい」だけは駄文。
2. **問いの設置と回収** — 問いの文そのものと、回収の文。「何をしないか」の宣言は含まない。
3. **読者への依頼・断り** — 章の冒頭・結びなどの境界に置く。中盤の論証に混ぜない。
4. **例の枠の開閉** — 架空の例を開く文（「〜としよう」）と閉じる文。境界に置く。

削除の手順。まず削って前後を読み、つながればそれで終わり。論理が飛ぶなら、その文が指そうとしていた
内容を状況側の文に書き換える。書き換えた結果がまだ本文自身を話題にしているなら、その書き換えは失敗。
上の4形に収まらない限り、文ごと削除して前後を橋渡しし直す。

## 拍と波形

- 短文で足場を打ち、長めの文で流し、短文で止める。
- 断定と逡巡を交互に置く。断定は「〜だった」「〜である」、逡巡は「〜に違いない」（あとで裏切られる思い込み）「〜だろうか」。
- 密な段落が2〜3個続いたら、疎の段落を1つ置く。疎の段落の機能は、確定事項の一行固定、次の判定対象の提示、視点距離の切替のいずれか。
- 転回点では「譲歩→転回→短い停止」を使える。転回のあとの短い指示文が読者の視線を固定する。

## 入り方と閉じ方

- 冒頭の仕事は、最初の数文で未回収の緊張を一つ作ること。型は問わない。読者の実感の言い直し、直接の問いかけ（ただし置き去りにせず答えを返す）、あとで試される一般命題、思い込みを書き切ってから事実で崩す、など。
- 節の頭で「本節では〜を扱う」と宣言しない。直前の節が残した違和感を当事者の問いとして言い直すか、読者が当然抱く反問をそのまま書くか、書き手の告白から入る。予告を置いてよいのは章の冒頭・結びの境界だけで、態度を帯びた一〜二文に限る。
- 節と節の橋は、前節の末尾ではなく次節の頭に置く。
- 理論・概念・引用は、読者の中に「まだ名前のない違和感」を作ってから導入する。理論は答えではなく命名として入れる。
- 性質や分類を列挙したら、各項目を直前の具体的な場面へ一つずつ着地させる。
- 途中で立てた問いは明示的に回収する。回収を2回に分けると後半の推進力になる。ただし分割の操作を本文で宣言しない。
- 結びは、積んだ抽象を読者がすでに持っている具体へ着地させてから閉じる。緊張は最後に一つだけ開いたまま残してよい。

## 執筆後の点検手順

1. **話題テスト** — 段落の頭の文と独立した短文をすべて拾い、状況か文書かを判定する。文書側は上の4形に該当しない限り削除または書き換え。推敲で新しく書いた文にも、書いた直後にかける。
2. **漏出テスト** — この規範の語彙（「答えの半分」「緊張」「回収」「線を引く」「拍」等）が本文にそのまま現れていないか検索する。現れていれば装置を宣言した証拠なので削除し、内容の側で実現し直す。
3. **緊張台帳** — 立てた問い・思い込み・約束を列挙し、それぞれの回収位置を行で指す。指せないものは回収を書き足すか、問いごと削る。
4. **拍の点検** — 長い断定文が3つ以上連続している箇所を探し、短い足場か停止、または逡巡を挿む。
5. **境界の点検** — 二人称の呼びかけ・依頼・謙抑が本文中盤にないか確認する。あれば境界へ移すか削る。

## 症状から処方を引く

- **全段落が同じ調子で疲れる** → 手順4（拍の点検）
- **正しいのに読み進める気がしない** → 冒頭に緊張を作り、手順3で以降も常に一つ開いていることを確認
- **理論の節で急に温度が下がる** → 理論の前に反問か告白を置き、列挙は場面へ一項目ずつ着地させる
- **緩い文はあるのに弛んで見える** → 手順1。緩みが進行実況になっている
- **章末が説教くさい** → 読者がすでに持っている具体へ着地させ、未決の問いを一つ残す
- **冒頭が事務的** → 態度のない議題表になっている。予告に態度を与えるか、読者の実感・抵抗の処理を先に置く
