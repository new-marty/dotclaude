## 結論

1. 資料の核は共通している。目的から型を選ぶ、比較対象を添える、色は意味のためだけに使い数を絞る、棒は原点0、凡例より直接ラベル、飾りは足さない。一次資料が複数一致する部分は高確度で使える。
2. Marty の Lumen 規則のうち、スケール・単位の明示、補間しない折れ線、同データ=同色、ゲージに数字を付ける、重複を出さないは、出典で裏づく(第5章)。
3. 食い違いは2点ある。ドーナツ優先と横棒禁止は、デジタル庁・Few・Pajamas・Datawrapper が棒を推すのと逆向き。Copilot の主役チャートに軸と min/max が無いのは、Lumen の D1(単位と min/max を図の内側へ)と逆。どちらも Marty に1問ずつ確認する価値がある。
4. 好きな3件の共通点は「小さな面積に意味のある色を置き、文字は中立色のまま」。ステータスのチップ、点、リング、差分のコールアウトが色を担当し、大きな面は白か紺で静かに保たれる。Few のルール5(柔らかい色を基調に、注意が要る所だけ鮮やかに)と Datawrapper(グレーが最重要の色)に対応する。
5. 空白も多い。Globality と Ant Design の「レイアウト適応規則」は本文が取れず、動きの数値・日本語の数値単位・モバイルのダッシュボード規則・小さい複数の一次説明は見つからなかった(Gaps)。

1. 情報密度が高いが、視覚的な重みは軽い。文字は小さく中立で、色と太さは意味のある所だけ。
2. 状態を色の面ではなく、点・チップ・リング・コールアウトで表し、同じ意味は同じ色。
3. 比較や差分が、数字のすぐ近くにある(件数、`$100 under`、`+482 −37`)。
4. 嫌いだった「ミニマルなマーケティングページ」(Vercel、Zed など)との違いは、見せる対象が空白と見出しではなく、データと状態であること。
