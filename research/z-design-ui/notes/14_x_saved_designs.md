- 保存の大半は AI・エージェント系の話題で、純粋なデザイン保存は少ない。UI として見て保存したと言えるのは約 28 件。
- 好みは「明るい白地で、情報密度が高く、薄い線と淡い色の意味づけで整理された UI」と「暗い地に 1 色の発光だけを置く演出」の 2 系統に分かれる。

- 日本語組版(palt・line-break・auto-phrase)の保存もあり、Lumen が日本語 UI なら取り込む価値がある。

## 共通する好み

1. **二系統に割れる。** 白〜極薄灰の面で密度高く並べる系(#4 #6 #9 #10 #11 #26 #27)と、黒に 1 色の発光を置く系(#1 #12 #15 #17 #18)。後者は動画・ランディング向けの見せ方として保存されていて、日常ツールの UI としては前者が多い。
2. **線は薄く細い。** 白い UI のほぼすべてが 1px の淡い枠で、濃い影はない。影はぼかしの薄いものか、無い。
3. **色は意味で使う。** 緑 = 追加・完了、赤 = 削除・バグ、青 = 選択・送信、紫・黄・橙 = 種別。#5 の「確かめた / 問い / 例」、#26 の「Works / Bug / Fixed」、#27 のパステル 5 色が代表。アクセントの主役は 1 色にとどまる(#10 の青、#15 の黄、#12 の紫)。
4. **数字と等幅フォント。** 大きい数字(#7 #8 #24)、桁揃え(#23 #21 の tabular-nums)、等幅の小ラベル(#6 #16 #5)。数値を 8 の倍数に揃える話(#9)も保存している。
5. **密度は高い。** 余白が広い系(#1 #4 #28)もあるが、フロー図や差分は 1 画面に多くの行を詰める(#6 #10 #16)。「スカスカにしない」好みに見える。
6. **角丸は 12〜24px。** 入力欄とカードは丸め、ボタンはピル(#3 #10 #15 #25)。
7. **ターミナル風の文字組。** 見出しや説明を等幅にし、本文だけ可読性の高い書体にする(#16 #28)。
8. **細部の品質への関心。** 余白(#9)、good-css(#21)、日本語組版(#22)、↗ の付け方(#19)。「雰囲気」より具体的な技の保存が目立つ。

## beautifului・Lumen との関係

| 観点 | beautifului.dev 型 | Lumen | X の保存 | 判定 |
|---|---|---|---|---|
| 地の色 | オフホワイト | 暖かい紙色 | 白〜極薄灰が主。暖かい白は #25 の 1 件のみ | beautifului と一致、Lumen の紙色は弱い |
| 書体 | Inter | 未確認(本調査では見ていない) | Inter 系の太字見出し + 等幅(#5 #6 #16 #28) | 一致 + 新(等幅を混ぜる) |
| 枠・影 | 1px の淡い輪 | 白い 20px の角丸カード | 1px の淡い枠。角丸は 12〜24px | 一致 |
| 色 | 意味つきチップ | ブランド青 1 色 | 意味色(緑 / 赤 / 青)と 1 色アクセント | 両方と一致 |
| 数字 | 記述なし | 大きい数字 | #7 #8 #24 が同じ好み | Lumen と一致 |
| 暗い UI | 範囲外 | 範囲外 | 発光する配線、紫の光線、アイソメ(#1 #17 #18) | 新 |
| 図解 | 範囲外 | 範囲外 | 意味色の箱で状態を見せる(#26 #27 #6) | 新 |
| 日本語組版 | 範囲外 | 日本語 UI なら必要 | palt、line-break、auto-phrase(#22) | 新 |

- 一致する点は、薄い線、白い面、意味色、1 色アクセント、大きい数字。Lumen の方針を変える材料は出なかった。
- 違う点は 2 つ。X 側は暖かい紙色をほとんど選んでいない(Lumen の紙色は X の保存からは裏づけが取れない)。もう一つは密度で、X 側は Lumen より詰める方向に寄る。
- 新しい点のうち取り込みやすいのは、状態を意味色の箱で見せる図解(#26)と、日本語組版の CSS(#22)。暗い UI の発光は、Lumen にダークモードを作る場合にだけ参考になる。
