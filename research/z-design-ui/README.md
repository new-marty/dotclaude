# z-design-ui の調査記録

UX の設計を受けて見た目と実装を担う UI スキルを作る前に集めた調査(2026-10)。スキルの実行時には読まれない。

- `playbook.md`: 理由のある UI を作るための知識を、決める順番と理由の書き方にまとめたもの。最初に読む。
- `principles.md`: 個々の原則を、理由・値・使わない場面・出典つきで引ける一覧。
- `report.md`: 最初の調査レポート(良い UI の条件、好みの第一報)。好みの部分は `playbook.md` の第4節が新しい。
- `notes/`: 調査ノート。
  - 01 GoodLinks の保存から読んだ好み、06 beautifului.dev の系統の実測、14 X に保存したデザイン、08 Lumen に残る Marty の言葉。
  - 02 良い UI の原則と論争、03 視覚の基礎と既定値、04 UI 実装で考えること、07 場面ごとの作法(文字サイズ、説明の量、動き、構造、数字、ダークとライト)。
  - 09 色、10 配置、11 大きさの決め方と理由の書き方、12 デザインの根拠と「魂」、13 エージェントに UI を作らせる実践、05 既存の AI 向け UI スキル。
  - 15 Marty が共有した動画、16・17 UI を教える YouTube の作者、18 書籍と記事、19 日本語の実践、20 リデザインと批評の事例、21 データ可視化(デジタル庁のダッシュボードガイドブックほか)と参照25件への回答の分析。

ノートはエージェントが Web 検索、動画の字幕、保存ページの本文から集めたもので、要約経由の引用が多い。各ノートの Gaps 節に未確認の点がある。
